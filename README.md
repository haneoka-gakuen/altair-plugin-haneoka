# Altair Haneoka

Browses Haneoka catalog resources and imports stories into Altair.

```sh
pnpm add @haneoka/altair @haneoka/altair-plugin-adv @haneoka/altair-plugin-haneoka
```

```ts
import { createAltairHaneokaPlugin } from "@haneoka/altair-plugin-haneoka";
```

Applications provide transport and localization adapters. An explicit release takes priority, followed by locale selection and the configured default release. The package contains no game assets or proprietary character runtimes.
